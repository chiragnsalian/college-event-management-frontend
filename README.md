**College Event Management System**

A full-stack web application designed to simplify the management of college events, including event creation, student registration, attendance tracking, and certificate management.

The system provides separate modules for Students, Organizers, and Administrators, with role-based access and dedicated dashboards.

Frontend:
college-event-management-frontend-gold.vercel.app

Backend API:
(https://college-event-management-backend-qfkf.onrender.com)

**Student Module**
Student registration and login,
Browse available college events,
View event details,
Register for events,
View registered events,
Attendance tracking,
Access generated certificate,
Responsive interface for mobile and desktop

**Organizer Module**
Organizer dashboard,
Create new events,
Manage created events,
Edit and delete events,
View event registrations,
Manage attendance,
QR-based attendance functionality,
Certificate management

**Admin Module**
Admin dashboard,
Manage students,
Manage organizers,
Manage all events,
Manage certificates,
Role-based administrative access
